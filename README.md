# Desafio POO I - Cadastro de Participantes

O projeto representa uma plataforma de eventos que cadastra participantes de campeonatos, cosplay e palestras.
A classe `Participante` é o molde dos objetos e possui os atributos nome, email e tipoParticipacao.
Os atributos são privados, aplicando o conceito de encapsulamento.
O acesso e a alteração dos dados são realizados por construtor, getters e setters.
O método `exibirInformacoes()` apresenta nome, e-mail e tipo de participação.
Foram criados três objetos diferentes: Ana (Cosplay), Bruno (Campeonato) e Carla (Palestra).
Os três objetos foram exibidos no console e também foi testada a alteração do e-mail de Ana.

## Como executar
1. Instale o Java JDK.
2. Abra o terminal na pasta do projeto.
3. Execute `javac Participante.java Main.java`.
4. Depois execute `java Main`.
